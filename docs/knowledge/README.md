# 知识文档索引

这个目录放项目内部长期知识，避免根目录混杂产品说明、交接资料和开发入口。

## 文档分工

- `../../README.md`：面向读者/用户的产品介绍。
- `../../AGENT_HANDOFF.md`：面向接手 Agent 的当前项目地图，保留在根目录方便优先发现。
- `PRODUCT_SPEC.md`：原始产品愿景和阶段规划，部分内容已与现状偏离，只作为北极星参考。
- `../../drama-edit/PLANNED.md`：本地编辑器协作流和后续事项。

## 使用原则

- 现状判断优先读 `AGENT_HANDOFF.md` 和代码。
- 产品方向讨论再读 `PRODUCT_SPEC.md`。
- 编辑器协作和内容包流转读 `drama-edit/PLANNED.md`。
